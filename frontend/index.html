How to use this

  1. Choose an algorithm on the left. The plot switches between regression, classification and clustering mode to match it.
  2. Get some data. Either pick a generated dataset, or click straight on the plot to place your own points. In classification mode the coloured buttons above the plot choose which class you are placing.
  3. Tune the hyperparameters and press Train. With Auto-run on (the default) every change applies immediately; switch it off and changes are staged until you press Generate for data or Train for the model.
  4. Scrub through the animation. Each frame is one real step of the algorithm — an epoch, an iteration, a level of depth — not a decorative transition.

Plot controls

  • Click — add a point
  • Drag a point — move it and watch the model follow
  • Shift-click or right-click a point — delete it
